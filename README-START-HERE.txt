========================================
PG CORRESPONDENCE — START HERE
========================================

This is SOURCE CODE, not an .exe.
Do NOT expect the app to open just by unzipping.

ON THE RECEIVING PC:
1. Install Node.js 20 LTS from https://nodejs.org
2. Install / open XAMPP and START MySQL
3. Unzip this folder
4. Double-click:  SETUP-AND-RUN.bat
5. Wait until it finishes install + database setup
6. Browser: http://localhost:3000

Later days: double-click START.bat (MySQL must be running).

If SETUP fails on database:

  Create database: postgraduate_correspondence
  Run SETUP-AND-RUN.bat again.
